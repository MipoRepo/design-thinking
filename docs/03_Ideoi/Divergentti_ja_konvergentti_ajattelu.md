# Divergentti ja konvergentti ajattelu

**Prosessin vaihe:** 03 Ideoi (koko prosessi)
**Liittyy:** [[Ideoinnin menetelmät]], [[Ideoiden valinta ja priorisointi]], [[Prosessimallit]]

---

## Määritelmä

- **Divergentti ajattelu:** laajentava, vaihtoehtoja avaava ajattelu. Tavoitteena on tuottaa mahdollisimman paljon erilaisia ideoita.
- **Konvergentti ajattelu:** kaventava, valintoja tekevä ajattelu. Tavoitteena on arvioida vaihtoehtoja ja valita parhaat.

## Keskeiset asiat

- Design thinking vuorottelee näitä kahta: **laajenna, sitten kavenna**.
- Kumpikin tarvitaan, mutta **ei samaan aikaan**: arvostelu tappaa ideoinnin.
- Ilmenee myös Double Diamond -mallin kahdessa timantissa.
- Ideoinnin alussa määrä ohittaa laadun, valinnassa laatu ohittaa määrän.

## Vertailu

| | Divergentti | Konvergentti |
|---|---|---|
| **Tavoite** | Mahdollisimman monta vaihtoehtoa | Parhaiden valinta |
| **Asenne** | Avoin, leikkisä, "kyllä, ja..." | Kriittinen, harkitseva |
| **Arviointi** | Lykätään | Tehdään kriteerien mukaan |
| **Tulos** | Ideoita, vaihtoehtoja | Päätös, rajaus |
| **Esimerkki** | Brainstorming, Crazy 8s | Äänestys, matriisi |

## Miten käytetään prosessissa

```
Empatisoi:   laajenna (kerää tietoa)
Määrittele:  kavenna (valitse ongelma)
Ideoi:       laajenna (ideoi) → kavenna (valitse)
Prototypoi:  kavenna (tee konkreettiseksi)
Testaa:      laajenna (palaute) → kavenna (päätökset)
```

## Edellytykset divergentille ajattelulle

- Turvallinen ilmapiiri, jossa ideoita ei arvostella
- Selkeä kysymys (HMW)
- Aikaraja ja visuaalinen tekeminen
- Rohkeus villeihin ideoihin

## Edellytykset konvergentille ajattelulle

- Selkeät **kriteerit** (käyttäjätarve, toteutettavuus, kannattavuus)
- Läpinäkyvä päätöksenteko
- Käyttäjän tarpeiden pitäminen keskiössä

## Yleisiä virheitä

- Arvostellaan ideoita liian aikaisin
- Tyydytään ensimmäiseen hyvään ideaan
- Valitaan ilman kriteerejä tai vain "mututuntumalla"
- Kavennetaan liian nopeasti

## Yhteenveto omin sanoin

Ensin avataan mahdollisuuksia mahdollisimman laajasti, sitten valitaan niistä parhaat kriteerien mukaan. Tärkeintä on pitää vaiheet erillään.
