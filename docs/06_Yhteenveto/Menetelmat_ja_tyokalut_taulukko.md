# Menetelmät ja työkalut -taulukko

---

## Käyttö

Nopea hakuteos: mikä menetelmä, mihin vaiheeseen, mihin tarkoitukseen ja milloin sitä käytetään.

## 01 Empatisoi

| Menetelmä / työkalu | Tarkoitus | Milloin käytetään |
|---|---|---|
| Haastattelu | Ymmärtää kokemuksia, motiiveja ja tunteita | Kun halutaan syvä ymmärrys |
| Havainnointi | Nähdä todellinen toiminta | Kun sanottu ja tehty voivat erota |
| Shadowing | Kokonaiskuva päivästä ja kontekstista | Kun rutiinit ja ympäristö ovat tärkeitä |
| Kysely | Laaja, määrällinen tieto | Oletusten vahvistamiseen |
| Empatiakartta | Kuvata käyttäjän sanat, ajatukset, teot, tunteet | Havaintojen jäsentämiseen |
| Persoona | Tehdä käyttäjäryhmä konkreettiseksi | Päätöksenteon tueksi |
| Asiakaspolku | Kuvata kokemus ajan yli | Ongelmakohtien löytämiseen |

## 02 Määrittele

| Menetelmä / työkalu | Tarkoitus | Milloin käytetään |
|---|---|---|
| Affiniteettikaavio | Ryhmitellä havainnot teemoiksi | Kun aineistoa on paljon |
| 2x2-matriisi | Vertailla kahden ulottuvuuden mukaan | Kuvioiden ja painopisteiden löytämiseen |
| POV-lause | Tiivistää käyttäjä, tarve ja oivallus | Ongelman määrittelyyn |
| HMW-kysymys | Kääntää ongelma ideoinnin lähtökohdaksi | Ennen ideointia |
| "Miksi?"-ketju | Löytää syvempi syy | Havainnon tulkinnassa |

## 03 Ideoi

| Menetelmä / työkalu | Tarkoitus | Milloin käytetään |
|---|---|---|
| Brainstorming | Paljon ideoita ilman arvostelua | Ryhmäideointiin |
| Brainwriting | Yksilöllinen ideointi ennen ryhmää | Kun halutaan kaikkien ääni esiin |
| SCAMPER | Muokata olemassa olevaa | Tuotteen tai palvelun kehittämiseen |
| Crazy 8s | 8 ideaa 8 minuutissa | Nopeaan visuaaliseen ideointiin |
| Mind map | Jäsentää ajatuksia ja yhteyksiä | Aiheen laajaan tarkasteluun |
| Pisteäänestys | Löytää ryhmän suosikit | Nopeaan valintaan |
| Vaikutus-vaiva-matriisi | Priorisoida vaikutuksen ja vaivan mukaan | Toteutuksen järjestyksen valintaan |
| Now-Wow-How | Erottaa helpot ja omaperäiset ideat | Rohkeiden ja realististen ideoiden valintaan |
| NUF-testi | Arvioida uutuus, hyöty, toteutettavuus | Ideoiden pisteytykseen |

## 04 Prototypoi

| Menetelmä / työkalu | Tarkoitus | Milloin käytetään |
|---|---|---|
| Paperiprototyyppi | Testata näkymiä ja käyttöliittymää | Varhaisessa vaiheessa |
| Storyboard | Kuvata käyttötilanne | Kokemuksen selittämiseen |
| Roolileikki | Kokeilla vuorovaikutusta | Palveluissa |
| Wireframe | Kuvata digitaalisen palvelun rakenne | Rakenteen ja polun testaukseen |
| Fyysinen malli | Testata muoto ja koko | Tuotteissa ja tiloissa |
| Wizard of Oz | Simuloida toimintaa | Kun teknologiaa ei vielä ole |

## 05 Testaa

| Menetelmä / työkalu | Tarkoitus | Milloin käytetään |
|---|---|---|
| Käyttäjätestaus | Kokeilla ratkaisua käyttäjillä | Prototyypin valmistuttua |
| Ääneen ajattelu | Selvittää käyttäjän ajatukset | Testauksen aikana |
| Loppuhaastattelu | Syventää havaintoja | Testin lopuksi |
| Feedback Capture Grid | Jäsentää palaute (I like, I wish, What if) | Palautteen kirjaamiseen |
| Iterointi | Parantaa palautteen perusteella | Jokaisen testikierroksen jälkeen |

## Yhteenveto omin sanoin

Jokaiseen vaiheeseen kuuluu omat menetelmänsä, ja niistä valitaan sopivat tilanteen ja oppimistavoitteen mukaan.
